# Poetry Generation with PyTorch

A character-level GPT-style language model trained to generate poetry. This model is pre-trained on a general text corpus and fine-tuned on poetry data.

## Overview

This project implements a language model using a Transformer architecture similar to GPT. The model is:

1. Pre-trained on BookCorpus data to learn general language patterns
2. Fine-tuned on poetry to specialize in generating poetic text

The model can generate new poems from prompts with controllable parameters for creativity.

## Features

- Character-level language modeling for fine-grained text generation
- Temperature-controlled text generation
- Interactive poem generation interface
- Adjustable generation parameters (length, creativity)

## Requirements

- Python 3.6+
- PyTorch 1.7+
- CUDA-capable GPU (recommended, but CPU works too)

## Usage

The interactive interface allows you to:
- Choose from predefined prompts or create your own
- Set the maximum length of generated text
- Adjust the temperature parameter for creativity

### Parameters

- `temperature`: Controls randomness in generation
  - Lower values (e.g., 0.5): More focused, deterministic text
  - Higher values (e.g., 1.2): More diverse, creative text
- `max_tokens`: Maximum length of generated poem

## Model Architecture

- Transformer-based architecture with self-attention
- 6 transformer layers
- 8 attention heads
- 256 embedding dimensions
- Character-level tokenization
- 256 context window size

## Model Performance

- **Pre-training final metrics**: loss 0.8897, accuracy 71.83%
- **Fine-tuning final metrics**: loss 1.3893, accuracy 56.51%

The pre-training phase showed significant improvement from the initial accuracy of 0.52% to a final accuracy of 71.83%, demonstrating the model's ability to learn general language patterns. During fine-tuning on poetry data, the model adapted to the specific style and structure of poems, achieving a final accuracy of 56.51%.

## Training Data

The model is trained in two phases:
1. Pre-training: BookCorpus dataset (cleaned subset)
2. Fine-tuning: Poetry corpus

## Files

- `train_model.py`: Script for training and fine-tuning the model
- `generate_poems.py`: Interactive interface for poem generation
- `pretrained_model.pth`: Pre-trained model checkpoint
- `finetuned_poem_model.pth`: Fine-tuned poetry model checkpoint
